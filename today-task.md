### 1. Scenario: Student grade manager
**Description:**  
You are building a small system for a teacher.

**Tasks:**
- **Input:** Ask the user how many students there are.
- **Collect:** For each student, ask their name and score.
- **Process:**
    - Calculate the average score.
    - Find the highest and lowest score.
- **Output:**
    - Print the class average.
    - Print the name and score of the top student.
    - Print the name and score of the lowest student.

---

### 2. Scenario: Simple shop checkout
**Description:**  
You are coding a mini checkout system for a shop.

**Tasks:**
- **Input:** Let the user enter product names and prices in a loop until they type `"done"`.
- **Process:**
    - Calculate total price.
    - If total > 50, apply a 10% discount.
- **Output:**
    - Show list of items.
    - Show total before discount, discount amount, and final total.

---

### 3. Scenario: To-do list manager
**Description:**  
You are building a command-line to-do list.

**Tasks:**
- **Features:**
    - Add a task.
    - List all tasks.
    - Mark a task as done.
    - Delete a task.
- **Data structure:** Use a list of dictionaries like:  
  `{"title": "Buy milk", "done": False}`

### 4. Scenario template you can reuse

You can create your own practice like this:

- **Context:** Who is using the program? (teacher, shop owner, student, gamer, etc.)
- **Goal:** What problem are they trying to solve?
- **Inputs:** What information will the user enter?
- **Processing:** What calculations or logic are needed?
- **Outputs:** What should the program show at the end?

Example template:

> **Context:**  
> You are building a program for a [user type].
>
> **Goal:**  
> Help them [main goal].
>
> **Input:**
> - [input 1]
> - [input 2]
>
> **Process:**
> - [step 1]
> - [step 2]
>
> **Output:**
> - [output 1]
> - [output 2]
